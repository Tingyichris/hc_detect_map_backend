# CLAUDE.md — hcdmap backend (API + MySQL)

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Standalone project. Sibling projects `server/` (fusion engine) and `frontend/` are separate
repos. Contracts this project must honour are in `docs/`: `api-contract.md`, `map-schema.md`,
`mqtt-contract.md` (only for the `config/map` signal it publishes).

## What it does

Owns all durable business data. Receives the fusion server's **idempotent** result feed
(pickups, anomalies, camera status), serves the frontend (dashboard + map editor), and
publishes the retained `sushi/<store>/config/map` MQTT signal when a new map is activated.

## Run

```
pip install -e ".[dev]"
docker compose up -d mariadb phpmyadmin       # DB + phpMyAdmin (:8080)
alembic upgrade head
python -m hcdmap_backend                        # uvicorn :8000, Swagger at /docs
pytest
```

Settings come from `HCDMAP_*` env vars (see `config/backend.example.toml` for the list) via
`settings.py` (pydantic-settings). Default `HCDMAP_DB_URL` targets the compose MariaDB.

## Layout

| Package | Responsibility |
|---------|----------------|
| `app.py` / `__main__.py` | FastAPI factory + uvicorn entrypoint. |
| `db.py` / `settings.py` | SQLAlchemy engine + session dep; env config. |
| `models/` | SQLAlchemy tables. Every business row carries `store_id` (`StoreScoped` mixin). |
| `schemas/` | pydantic request/response models — mirror `docs/api-contract.md`. |
| `api/ingest.py` | result feed from the fusion server. **Idempotent**: `event_id` unique, upsert. Service-token auth. |
| `api/maps.py` | versioned map CRUD; `activate` publishes the `config/map` signal via `config_signal/`. |
| `api/sessions.py` | table-session lifecycle, bill = `plate_classes.price` × counts (frozen at close). |
| `api/review.py` / `api/corrections.py` | low-confidence pickup queue; audited manual tally fixes. |
| `sessions/lifecycle.py` | session state machine; a pickup auto-attaches to the table's open session. |
| `pos/` | `PosAdapter` interface + `ManualPosAdapter` (default: dashboard buttons). `RealPosAdapter` TBD. |
| `config_signal/publisher.py` | paho-mqtt retained publish of the map-reload signal. |
| `auth/` | STUB — users (`floor` / `manager`), service token, WS token. `api/deps.py` currently accepts any header. |

## Rules

- `api/ingest.py` is the ONLY automated writer of `pickup_events`. Retries and a fusion
  restart re-POST the same `event_id` → do nothing. Never make ingest non-idempotent.
- A correction writes a `corrections` row and adjusts the *derived* tally — it never edits a
  `pickup_events` row.
- `maps` rows are immutable; "edit" = new version. Exactly one row per store has `active=True`.
- Bills are derived on read; only a closed `table_sessions` row stores frozen totals.
- `migrations/0001_initial.py` uses `create_all` as a bootstrap. Replace with a real
  autogenerated revision (`alembic revision --autogenerate`) once the DB is reachable.

## Conventions

- ruff lint + format (hook on save). `src/` layout. Python ≥ 3.11.
